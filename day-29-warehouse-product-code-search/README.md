# Day 29 — Warehouse Product-Code Search

## 1. Problem

A warehouse stores product-code characters in a grid.

The system must determine whether a given product code can be formed
by moving through adjacent cells.

Allowed movement:

- Up
- Down
- Left
- Right

Diagonal movement is not allowed.

A grid cell cannot be reused within the same path.
